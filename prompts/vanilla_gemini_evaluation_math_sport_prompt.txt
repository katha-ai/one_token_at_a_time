Your task is to evaluate the accuracy of an AI model's response against strictly defined Ground Truth (GT) data.

### Input Data Context

1. Sport_Text: The original text prompt containing the sport text.
2. Math_Question: The original text prompt for the math puzzle.
2. GT_Sport: The correct sport answer based on the text.
3. GT_Math: The correct numerical answer to the math puzzle.
4. Model Response: The text generated by the AI model.

### Your Evaluation Logic

Step 1: Analyze Response Status
- Check if response is empty, gibberish, refused ("I cannot..."), or "Truncated" (cuts off mid-sentence).
- If Refused/Truncated, skip accuracy checks.

Step 2: Evaluate Sport Accuracy
- Extract the sport from 'Model Response'.
- Handle Negation: If the model says "No [GT_Sport]", it is Incorrect.
- Synonyms: Allow reasonable synonyms (e.g., Football = Soccer).
- Compare against 'GT_Sport'. Logic must match even if formatting differs.

Step 3: Evaluate Math Accuracy
- Extract the final number from 'Model Response'.
- Compare against 'GT_Math'. Logic must match even if formatting differs ($10 vs 10.00).

Step 4: Assign Overall Category
Rules for 'overall_category':
- Answered-Correctly: BOTH Sport and Math are correct.
- Answered-Incorrectly: Either Sport OR Math (or both) are incorrect.
- Unanswered: The model refused, the response is empty, or the response is cut off before providing any answers.

### Output Format (JSON)
Output a valid JSON object.

{
  "sport_evaluation": {
    "mentioned_sport": "string",
    "is_correct": boolean,
    "negation_detected": boolean
  },
  "math_evaluation": {
    "extracted_value": "string",
    "is_correct": boolean
  },
  "overall_category": "Answered-Correctly" or "Answered-Incorrectly" or "Unanswered"
}

### Evaluate the Following:
Model Response: {{model_response}}
Sport_Text: {{sport_text}}
GT_Sport: {{gt_sport}}
Math_Text: {{math_text}}
GT_Math: {{gt_math}}
