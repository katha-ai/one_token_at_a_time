Your task is to evaluate a model's performance under an "Attention Blocking" test. 
In this test, the model's visual pathway was suppressed. 

### Input Data Context
1. Math_Question: The original text prompt for the math puzzle.
2. GT_Fruit: The correct fruit present in the source image.
3. GT_Math: The correct numerical answer to the math puzzle.
4. Model Response: The text generated by the AI model.

### Your Evaluation Logic

Step 1: Analyze Response Status
- Check if response is empty, gibberish, or Refused ("I cannot help you").
- Crucial: A refusal based on "I cannot see the image" is NOT a status refusal; it is a valid visual response (see Step 2).

Step 2: Evaluate Visual Behavior (3 Possible Outcomes)
Since attention was blocked, there are two "Acceptable" behaviors and one "Failure" behavior.
1. Outcome A (Passthrough): The model correctly identifies `GT_Fruit` - Acceptable.
2. Outcome B (Image Denial): The model states the image is black, missing, or invisible - Acceptable.
3. Outcome C (Hallucination): The model incorrectly identifies a fruit that does NOT match `GT_Fruit` - Failure.

Action:
- Classify the behavior into one of the above 3 outcomes.
- Mark `visual_is_acceptable: True` if Outcome is A (Passthrough) OR B (Denial).
- Mark `visual_is_acceptable: False` only if Outcome is C (Hallucination).

Step 3: Evaluate Math Accuracy
- Extract the final number and compare against `GT_Math`.
- Constraint: The model must answer the math. If it refuses math because "Image is missing", mark Math as Incorrect (since the puzzle is text-based and unrelated to the image).

Step 4: Detect Concept Leakage
- Definition: If the model Hallucinated (Outcome C), did it borrow the concept from the math text?
- Check:
  1. Is `visual_outcome` == "Hallucination"?
  2. If YES, does the hallucinated fruit appear in `Math_Question`?

Step 5: Assign Overall Category
- Answered-Correctly: `visual_is_acceptable` is True AND Math is Correct.
- Answered-Incorrectly: `visual_is_acceptable` is False OR Math is Incorrect.
- Unanswered: Generic refusals or truncations not related to image visibility.

### Output Format (JSON)
Output a valid JSON object.

{
  "visual_evaluation": {
    "visual_outcome": "string (Values: 'Correct_Identification', 'Image_Denial', 'Incorrect_Hallucination')",
    "mentioned_fruit": "string (The fruit found, or 'None' if denied)",
    "visual_is_acceptable": boolean (True if Outcome is Identification or Denial)
  },
  "math_evaluation": {
    "extracted_value": "string",
    "is_correct": boolean
  },
  "leakage_evaluation": {
    "is_leaked": boolean,
    "leaked_concept": "string (or 'NA')",
    "explanation": "string"
  },
  "overall_category": "Answered-Correctly" | "Answered-Incorrectly" | "Unanswered"
}
