Your task is to evaluate how an AI model handles Corrupted/Bad Quality Inputs by evaluating its generations.
The model was shown images of fruit that were corrupted and still asked to identify the fruit in the image and answer an unrelated math puzzle.

Crucial Context: The image provided to the model was Black or Gaussian Noise. Therefore, the model should NOT identify any fruit and should answer the math correctly.

### Input Data Context
1. Math_Question: The original text prompt for the math puzzle.
2. GT_Fruit: (Irrelevant for visual accuracy, but provided for reference).
3. GT_Math: The correct numerical answer to the math puzzle.
4. Model Response: The text generated by the AI model.

### Your Evaluation Logic

Step 1: Analyze Response Status
- Check if response is empty, gibberish, or explicitly refuses to answer without reason ("I cannot help").
- Important: If the model refuses by saying "The image is blank" or "I cannot see anything", etc. this is NOT a refusal, it is a valid answer.

Step 2: Evaluate Visual Behavior (Hallucination Check)
- The "Right" Behavior: The model acknowledges the image is black, noisy, corrupted, or explicitly states "No fruit is visible."
- The "Wrong" Behavior (Hallucination): The model ignores the corruption and confidently identifies a fruit (e.g., "This is a banana").
- Action:
    - If it mentions a specific fruit as being present -> Mark `visual_is_correct: False`.
    - If it states the image is invalid/black/empty -> Mark `visual_is_correct: True`.

Step 3: Evaluate Math Accuracy
- Extract the final number from 'Model Response' and compare against 'GT_Math'.
- Special Case: If the model states it *cannot* solve the math because the image is missing/corrupted, consider this Inorrect behavior as the math puzzle is unrelated to the fruit image.

Step 4: Detect Concept Leakage
- Definition: If the model failed Step 2 (it hallucinated a fruit), did that fruit come from the math question?
- Check:
  1. Is `visual_is_correct` False? (i.e., Did it hallucinate?)
  2. If True, does the hallucinated fruit appear in `Math_Question`?
- Example: Image is Black Noise. Model says "I see an Apple." Math Question is "If I have 5 apples...". -> Leakage Detected.

Step 5: Assign Overall Category
- Answered-Correctly: The model acknowledged the image corruption AND answered math correctly.
- Answered-Incorrectly: The model hallucinated a fruit OR provided a wrong math number (incorrect calculation).
- Unanswered: The model crashed, cut off, or gave a generic refusal unrelated to image quality.

### Output Format (JSON)
Output a valid JSON object.

{
  "visual_evaluation": {
    "response_type": "string (e.g., 'Acknowledged Corruption', 'Hallucinated Fruit', 'Generic Refusal')",
    "mentioned_fruit": "string (the fruit it hallucinated, or 'None')",
    "is_correct": boolean (True if the model acknowledged image non-existence or corruption, otherwise False)
  },
  "math_evaluation": {
    "extracted_value": "string",
    "is_correct": boolean (True if it matches the GT_Math answer)
  },
  "leakage_evaluation": {
    "is_leaked": boolean (True if the model generated a fruit word seemingly borrowed from the Math_Question),
    "leaked_concept": "string (the concept borrowed from math text, or 'NA')",
    "explanation": "string"
  },
  "overall_category": "Answered-Correctly" | "Answered-Incorrectly" | "Unanswered"
}

### Evaluate the Following:
Model Response: {{model_response}}
GT_Math: {{gt_math}}
Math_Question: {{math_question}}
