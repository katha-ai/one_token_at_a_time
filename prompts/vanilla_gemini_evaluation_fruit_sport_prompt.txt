Your task is to evaluate the accuracy of an AI model's response against strictly defined Ground Truth (GT) data and also check for "Concept Leakage" (hallucinations induced by the text prompt).

### Input Data Context
1. Sport_Text: The original text prompt for the sport text.
2. GT_Fruit: The correct fruit present in the image.
3. GT_Sport: The correct sport category answer to the sport text.
4. Model Response: The text generated by the AI model.

### Your Evaluation Logic

Step 1: Analyze Response Status
- Check if response is empty, gibberish, refused ("I cannot..."), or "Truncated" (cuts off mid-sentence).
- If Refused/Truncated, skip accuracy checks.

Step 2: Evaluate Fruit Accuracy
- Locate the mention of fruit in 'Model Response'.
- Handle Negation: If the model says "No [GT_Fruit]", it is Incorrect.
- Synonyms: Allow reasonable synonyms (e.g., Clementines = Oranges).
- Result: Determine if `fruit_is_correct`.

Step 3: Evaluate Sport Accuracy
- Extract the sport from 'Model Response'.
- Compare against 'GT_Sport'. sport should must match even if formatting differs, handle synonyms.

Step 4: Detect Concept Leakage
- Definition: Leakage occurs when the visual system fails and "borrows" a concept suggested from the text prompt instead.
- Check:
  1. Is `fruit_is_correct` True? - If correct fruit is generated by the model, ignore leakage ('NA').
  2. Is `fruit_is_correct` False? - does the `mentioned_fruit` appear as a noun/object in the `Sport_Text`?

Step 5: Assign Overall Cateogry

Rules for 'overall_category':
- Answered-Correctly: BOTH Fruit and Sport are correct.
- Answered-Incorrectly: Either Fruit OR Sport (or both) are incorrect.
- Unanswered: The model refused, the response is empty, or the response is cut off before providing any answers.

### Output Format (JSON)
Output a valid JSON object.

{
  "fruit_evaluation": {
    "mentioned_fruit": "string",
    "is_correct": boolean,
    "negation_detected": boolean
  },
  "sport_evaluation": {
    "extracted_value": "string",
    "is_correct": boolean
  },
  "leakage_evaluation": {
    "is_leaked": boolean,
    "leaked_concept": "string (the concept borrowed from sport text, or 'NA')",
    "explanation": "string (e.g., 'Model predicted ball because it appears in the sport text')"
  },
  "overall_category": "Answered-Correctly" or "Answered-Incorrectly" or "Unanswered"
}
